# Module 1.3 – Locators and Object Identification

## Objective

To identify web elements using Selenium locators and use CSS selectors and XPath for reliable element identification.

## Topics Covered

* ID locator
* Name locator
* Class Name locator
* Tag Name locator
* Link Text locator
* Partial Link Text locator
* CSS Selectors
* Advanced CSS selectors
* XPath
* Advanced XPath techniques

## Implementation

Selenium locators were used to identify and interact with web elements. CSS selectors and XPath expressions were implemented for precise element identification and dynamic element targeting.

## Validation

The locator and selector scripts were executed successfully to verify that the required web elements could be located and interacted with correctly.
