# Module 1.9 – Advanced Interactions

## Objective

To perform advanced mouse, keyboard, and scrolling interactions using Selenium WebDriver.

## Topics Covered

* Double click
* Right click
* Mouse hover
* Drag and drop
* Keyboard actions
* Keyboard shortcuts
* Scrolling
* Scrolling to a specific element

## Implementation

Selenium ActionChains was used to perform mouse interactions, keyboard actions, and scrolling operations. Screenshots were captured during execution to provide visual evidence.

## Validation

The mouse interaction and keyboard/scroll scripts were executed successfully. Each interaction was verified through the expected browser behavior and execution results.
