# Module 1.8 – Screenshots and Exception Handling

## Objective

To capture screenshots during Selenium execution and handle runtime exceptions safely.

## Topics Covered

* Taking screenshots
* Generic screenshot method
* Saving screenshots to a dedicated folder
* Try-except-finally blocks
* Handling Selenium exceptions
* Browser cleanup using finally

## Implementation

A reusable screenshot method was implemented to capture browser states during execution. Exception handling was also implemented using try-except-finally to handle Selenium errors and ensure proper browser cleanup.

## Validation

The screenshot script successfully captured the required browser states. The exception handling script successfully handled an invalid element scenario and executed the finally block to close the browser.
