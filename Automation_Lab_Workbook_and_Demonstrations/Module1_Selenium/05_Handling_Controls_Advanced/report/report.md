# Module 1.5 – Handling Controls Advanced

## Objective

To handle advanced browser controls and user interactions using Selenium WebDriver.

## Topics Covered

* JavaScript alerts
* Confirmation and prompt dialogs
* Date picker
* File upload
* Multiple windows and tabs
* Keyboard events
* Scrolling
* Drag and drop
* IFrames
* Enabled and disabled elements
* Getting text from elements
* Getting attribute values

## Implementation

Selenium WebDriver was used to interact with advanced browser controls, switch between windows, handle alerts, upload files, perform keyboard and mouse actions, work with frames, and retrieve element information.

## Validation

The implemented scripts were executed to verify the required interactions and element states. The IFrame concept was also studied and demonstrated during the section.
