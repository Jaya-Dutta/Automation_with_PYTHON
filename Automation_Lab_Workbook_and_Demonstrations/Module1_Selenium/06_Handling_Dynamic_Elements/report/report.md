# Module 1.6 – Handling Dynamic Elements

## Objective

To work with dynamic web tables and extract, locate, and validate table data using Selenium WebDriver.

## Topics Covered

* WebTable handling
* Table traversal
* Dynamic row and column identification
* Header and complete table data extraction
* Conditional row and cell search
* Table data validation

## Implementation

Selenium WebDriver was used to locate web tables, traverse rows and columns, extract table data, identify records dynamically, and validate specific values using assertions.

## Validation

The table scripts were executed successfully to verify table structure, dynamic row and cell identification, column detection, data extraction, and expected values.
