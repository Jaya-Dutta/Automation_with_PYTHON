# Module 1.4 – Handling Different Controls

## Objective

To understand how Selenium identifies and interacts with different types of web controls.

## Topics Covered

* Text boxes
* Buttons
* Checkboxes
* Radio buttons
* Links
* Dropdowns
* XPath-based control identification
* Advanced XPath techniques

## Implementation

Selenium WebDriver was used to locate and interact with different web controls. XPath-based techniques were also implemented to identify controls using attributes, text, and relationships between elements.

## Validation

The control-handling scripts were executed successfully to verify element identification and interaction with the required controls.
