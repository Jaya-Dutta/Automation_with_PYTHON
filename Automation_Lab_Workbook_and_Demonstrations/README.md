# Automation Lab Workbook & Demonstrations

A structured Python automation training workbook covering web automation, test frameworks, API automation, BDD, and Robot Framework. The modules are organized progressively to demonstrate practical automation concepts, reusable components, test execution, and framework development.

## Training Modules

### Module 1 — Selenium Web Automation

**Focus:** Web UI automation using Selenium WebDriver and Python.

This module covers the fundamentals of Selenium automation, including:

* WebDriver setup and browser automation
* Locators and web element interactions
* Form controls and advanced controls
* Dynamic web elements
* Explicit and implicit waits
* Screenshots
* Exception handling
* Advanced Selenium interactions

**Key Technologies:** Python · Selenium WebDriver · Chrome

---

### Module 2 — Unit Test Frameworks

**Focus:** Test automation using Python testing frameworks.

This module introduces structured test development and execution using:

* PyTest
* unittest
* Test fixtures and assertions
* Test execution and organization
* Selenium integration with test frameworks
* HTML test reporting

**Key Technologies:** Python · PyTest · unittest · Selenium · pytest-html

---

### Module 3 — API Automation and BDD

**Focus:** API test automation and behavior-driven development.

This module covers:

* REST API automation using Requests
* HTTP methods and response validation
* API test organization
* Behavior-Driven Development using Behave
* Feature files and step definitions
* Database interaction with MySQL
* Allure reporting

**Key Technologies:** Python · Requests · Behave BDD · MySQL · Allure

---

### Module 4 — Robot Framework

**Focus:** Keyword-driven test automation using Robot Framework.

This module introduces:

* Robot Framework fundamentals
* Test case and suite organization
* Script execution options
* Built-in and reusable keywords
* SeleniumLibrary integration
* Readable test structure
* Page Object and reusable keyword concepts
* Robot Framework execution reports

**Key Technologies:** Python · Robot Framework · SeleniumLibrary

---

## Technologies Covered

**Python · Selenium WebDriver · PyTest · unittest · Requests · Behave BDD · MySQL · Allure · Robot Framework · SeleniumLibrary**

## Training Progression

The modules demonstrate a progressive automation workflow:

```text
Selenium Web Automation
        ↓
Test Frameworks
        ↓
API Automation & BDD
        ↓
Robot Framework
```

The training combines UI automation, test framework development, API testing, BDD practices, reusable automation components, and test reporting.
